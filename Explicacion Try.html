[ Gestión de Excepciones ]

Como se usa? Codigo en vivo
#

Definicion: Es un mecanismo de comando que permite anticipar y con ello controlar situaciones que pueden detener el funcionamiento del programa.

Por que importan? Evitan Crasheos abruptos causados por respuestas invalidas a traves de inputs. Todos los comandos evitan los casos posibles donde esto podria pasar.

##

Antes VS Después

Código que es ineficiente 
Edad_usuario = int(input("Cual es tu edad? "))
Código que esta optimizado (Con try/except) 
try:
        Edad_usuario = int(input("Cual es tu edad? "))
      except ValueError:
        print("Tu respuesta no es valida")
###

Diagrama de Flujo Técnico

INICIO
↓
Usuario ingresa un valor
↓
try: Ejecutar código
↓
¿Qué tipo de error ocurre?
ValueError →
except ValueError:
Valor ingresado no válido
Ej: "veinte" en vez de 20
ZeroDivision →
except ZeroDivisionError:
División por cero
Ej: 10 / 0
FileNotFound →
except FileNotFoundError:
Archivo no encontrado
Ej: open("datos.txt")
Sin error →
else:
Código ejecutado sin errores
↓
Todas las ramas convergen aquí
↓
finally:
Ejecutar SIEMPRE
(Haya error o no)
↓
FIN

El flujo siempre pasa por try, se ramifica según el tipo de error en except, y converge en finally sin importar el camino tomado.

####

Simulador

MODO PELIGRO: El programa se detendrá ante cualquier error
MODO SEGURO: Los errores se manejan y el programa continúa
